# DECISIONS

1. **Build the narrow free tool, not the "all-in-one" editor (the evaluator said "Archive").** The machine-driven brief defines a version a machine can run alone: silence and filler trimming, captions and vertical export, on the device. That's a real, searched-for job ("remove silence from video", "auto caption video free") that incumbents gate behind accounts, uploads and watermarks. A full editor or the generative effect would need servers and money, so they're keys, not v1.
2. **Name: Symbaiosis.** It's the name in Jack's own note and it's distinctive. "Humends" and "Humesh" were the alternatives; neither says more. Public tagline: "free AI video editor in your browser".
3. **Everything on the device, enforced by CSP.** `connect-src 'self' blob: data:` on every page; the speech worker talks only to this site. Libraries, models, fonts and the sample are served from the repo. The self-test fails on any off-site request.
4. **Mediabunny + WebCodecs, not ffmpeg.wasm.** Mediabunny (MPL-2.0, ~0.7 MB) reads and writes MP4/MOV/WebM and uses the browser's hardware codecs; ffmpeg.wasm is ~30 MB, slower, and fast only with threads (which need cross-origin isolation). AAC: native where the browser has it, otherwise Mediabunny's WebAssembly AAC encoder (LGPL FFmpeg code, loaded only when needed).
5. **Single-threaded WebAssembly instead of a cross-origin-isolation service-worker shim.** GitHub Pages can't send COOP/COEP headers. A shim (coi-serviceworker) reloads the page on first visit and rewrites every response, which risks breaking caching and Safari. Whisper tiny.en on one thread transcribes ~20x faster than real time on an M-series Mac, so threads aren't needed. The worker uses up to four threads automatically if the site is ever served isolated (OPERATIONS.md key 5).
6. **Whisper tiny.en (43 MB) for English, Whisper base (80 MB) for 18 other languages, 8-bit ONNX, pinned revisions, committed to the repo.** Smallest models with usable accuracy; English is the default and fastest. Committing the weights (largest file 54 MB, under GitHub's 100 MB limit) means no runtime dependency on Hugging Face and no third-party request. Git LFS was rejected: its bandwidth quota would run out within a few deploys.
7. **Fillers: hesitation sounds only, never "like/so/you know".** Cutting meaningful words silently would damage videos. The model is prompted with hesitations so it writes them down; words the model misses show as wordless "sounds" the editor can cut.
8. **Words are aligned to the measured sound.** Whisper's word times drift around pauses (a word after a pause "starts" in the silence). Each word is placed inside the speech island it belongs to. Measured on the sample: edit length within 0.05 s of the script's prediction.
9. **Pauses are shortened, not deleted.** Natural pacing turns any pause of 0.5 s or more into 0.2 s (tight 0.12 s, relaxed 0.36 s), cut at the quietest point with 6 ms fades. Deleting pauses outright sounds robotic.
10. **No watermark; the "Edited with Symbaiosis" end card is opt-in.** The value promise is "no watermark". The share loop is the result screen's "Share this free tool" button, the open-source footer and the optional end card.
11. **The sample clip is synthetic.** Narration from Kokoro-82M (Apache-2.0 text-to-speech) with pauses and fillers placed at known times, picture drawn by code (a cartoon speaker whose mouth follows the voice). No person's voice or likeness; exact ground truth for tests; free to publish.
12. **Static site on GitHub Pages, guides by date.** Ten guides written up front; four live at launch, then one a week on Mondays. The scheduled deploy publishes them; a Claude routine can add more (OPERATIONS.md key 4).
13. **Custom domain: not chosen here.** Jack's portfolio had no match. The site's address is one setting (`SITE_URL`); the "domain rollout" session picks and points the domain.
